# Archivo Black display font

The `ArchivoBlack` bitmap-font atlas is generated from:

- Archivo Black Regular (Omnibus-Type)
- Source repository: `google/fonts` (`ofl/archivoblack`)
- License: SIL Open Font License 1.1 (see `OFL.txt`)

The atlas covers printable ASCII (codepoints 32-126). It is retained only for
explicitly numeric or ASCII-only poster readouts. General UI text, localised
labels, user input, and imported metadata use the complete `NotoSansCJK`
family instead.
