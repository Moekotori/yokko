# osu!lazer Noto UI font stores

These bitmap-font descriptors and atlas pages are copied without modification
from `ppy/osu-resources`:

- Source repository: `https://github.com/ppy/osu-resources`
- Source commit: `d8d01c29ce0f298159aea3644b947d8b4a1882a2`
- Source path: `osu.Game.Resources/Fonts/Noto`

Yokko registers the stores in the same order as osu!lazer. Chinese text uses
the bundled Noto Sans SC Medium CJK and Bopomofo stores, while Plus Jakarta
Sans remains the explicitly selected family for English, figures, and ASCII
punctuation.

See `LICENSE.txt` in this directory for the upstream font licence.
