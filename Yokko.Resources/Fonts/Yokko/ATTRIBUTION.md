# Yokko rounded localisation font

The `Yokko` and `Yokko-Bold` bitmap-font atlases are generated from:

- Chill Round Gothic Regular
- Chill Round Gothic Bold
- Source repository: `Warren2060/ChillRoundGothic`
- Source commit: `53505f0818983d2fcdda00dc66e051ad13e81ffb`

Chill Round Gothic is a rounded derivative of Source Han Sans SC. The source
font is licensed under the SIL Open Font License 1.1. The generated bitmap
subset is distributed under the same licence. Run
`scripts/generate-localisation-font.py` from the repository root to regenerate
the atlases from the strings currently used by Yokko.
