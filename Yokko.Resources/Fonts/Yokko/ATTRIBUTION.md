# Yokko localisation font

The `Yokko` and `Yokko-Bold` bitmap-font atlases are generated from:

- Noto Sans CJK SC Regular
- Noto Sans CJK SC Bold
- Source repository: `notofonts/noto-cjk`
- Source commit: `f8d157532fbfaeda587e826d4cd5b21a49186f7c`

The source fonts are licensed under the SIL Open Font License 1.1. The generated
bitmap subset is distributed under the same licence. Run
`scripts/generate-localisation-font.py` from the repository root to regenerate
the atlases from the strings currently used by Yokko.
