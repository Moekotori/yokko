# osu! SV compatibility corpus

`upstream-nan-control-points.osu` is copied from
`ppy/osu/osu.Game.Tests/Resources/nan-control-points.osu` at commit
`e63005df4b742d5e6520cef47870b1299722cac5` under osu!'s MIT licence.

The remaining minimal fixtures are Yokko regression charts derived from the
same legacy control-point rules. They cover same-time red/green precedence,
control-point bounds, inherited SV clamps, and long-note hidden-note ordering.
