# 设置预设与延迟校准

## 入口与数据

- 所有分类顶部都有「调延迟」和当前分类的「怎么设置」。搜索「调延迟」「声音不同步」「不跟手」并回车可直接打开校准；搜索「预设」可直接打开预设。
- 初次校准只显示「先听一下」和「开始跟拍」。短试听约两声节拍；主音量、节拍音量可在弹层调整。测量中显示剩余时间和停止按钮；可靠结果由主按钮确认应用，应用后可撤销，重试或下一首生效。
- 误差图、采样统计及原值/建议值对比默认收起，按「详细信息与对比」展开。
- 音频页和游玩时序页共用手动微调控件：直接输入整数（±200 ms）、±1/±10 ms 按钮及归零；Enter 确认、Esc 取消输入。判定偏晚应减小偏移，偏早应增大。
- 通用页的「玩法配置预设」提供六个命名槽位。保存玩法标量、全键数键位与快捷键、判定、皮肤和 HUD 布局；复制/粘贴 JSON 可迁移。覆盖和删除需在界面再次点击，载入可撤销。
- 预设不覆盖设备音频校准、无障碍偏好或选曲 MOD 组合。所需皮肤未安装时拒绝载入，先安装相同皮肤再试。
- 设备配置以 `音频后端:设备 ID` 为键保存音量、缓冲和偏移。新路由继承音量/缓冲、将偏移清零；首次迁移保留当前全局偏移。系统默认输出是独立路由，校准前建议显式选择具体设备，避免系统默认设备变化造成歧义。
- 配置预设、设备配置、无障碍开关都由 `YokkoConfigManager` 写入 `yokko.ini`。

## 校准的时序约定

`InputCalibrationSession` 属于 Core，仅接收未施加用户偏移的音频时间，不读取 UI 时钟或设备。

`AudioSettingsTestPlayer` 在实际所选后端播放预生成的 48 kHz 节拍 WAV。节拍位于 1000 ms 开始、每 500 ms 一次；前四拍热身，之后最多 36 拍，总长 21 秒。音频请求强制偏移为零，校准不会叠加已有偏移。

键盘使用现有 `KeyInputTimestampSource` 的原始事件或窗口事件时间，经 `ITimestampedAudioClock` 映射为音频呈现时间。缺少可靠时间戳时不回退到帧时间。每拍只取第一次按下，忽略重复、过早、乱序和范围外输入；采样时无节拍动画，减少视觉引导。

先求中位数和 MAD，以 `max(15 ms, 3 × 1.4826 × MAD)` 剔除异常值。建议必须同时满足：至少 24 个保留样本；保留比例至少 80%；稳健离散程度不超过 18 ms；原始样本前后两半中位数差不超过 12 ms；建议在 ±200 ms 内。超范围结果不截断成边界值。

GameplayClockSnapshot 使用 `audioTime + userOffset`，因此建议为 **负的原始跟拍误差中位数**。这是绝对偏移，不是对当前配置的增量。结果包含个人跟拍习惯，不能声称测出了纯硬件延迟。

## 状态与保护

- 先暂停主页音频并释放输出，再打开校准流；关闭时将音频释放任务交给主页的现有 handoff，以免返回主页抢占输出。
- 失焦、静音、后端/设备/缓冲变化、时钟倒退/停滞、断音和输出故障会使本轮失效。
- 不自动应用。原偏移/建议偏移各可再跑一轮跟拍验证，显示剩余误差分布；节拍音自身不改变。验证不稳定或建议验证残差大于 20 ms 时撤销建议，要求重新测量。
- 应用和撤销仅在测量设备及缓冲仍一致时允许。音频引擎释放后不暴露过期的时钟引用。

## 验证

Focused tests 覆盖偏移符号、热身/重复/乱序事件、样本不足、异常值、漂移、超范围、输出时钟与断音、设备切换与持久化、预设校验及撤销、设置弹层生命周期。

原生输出 smoke 通过 `YOKKO_RUN_AUDIO_SETTINGS_OUTPUT_TEST=1` 单独启用；它只能证明当前机器输出流和呈现时钟可用，不能代替玩家实际跟拍和多设备 A/B 校准。

视觉预览可用 `YOKKO_SETTINGS_PREVIEW=1` 配合 `YOKKO_SETTINGS_TOOL=Calibration|Presets`，或 `YOKKO_SETTINGS_PAGE=Accessibility`。验证时设置 `YOKKO_PORTABLE_TESTS=1`，并将构建输出放在 `F:\YokkoArtifacts`，避免使用正常用户配置目录。
