# Yokko 实时调试控制台

Yokko 提供默认关闭的游戏内实时调试控制台。按 `F12` 可在任意页面立即开启或关闭，也可以在“设置 → 通用 → 实时调试控制台”中切换；状态会写入 `yokko.ini`。

控制台直接订阅 osu!framework 的 `Logger.NewEntry`，不会轮询日志文件。后台导入、音频与输入线程写出的日志会在下一次更新帧中增量显示，同时仍按 framework 的原始分类落盘到 `%APPDATA%\Yokko\logs`。

控制台开启时会同时启动性能采样，即使“显示 → 性能读数”卡片处于关闭状态也会继续监测。控制台顶栏实时显示 DRAW FPS/P99、UPDATE 帧时间/P99、进程 CPU、工作集内存和各代 GC 次数；详细样本每秒写入日志。检测到帧预算持续超限时会写入 `frame-pacing-alert`，恢复后写入 `frame-pacing-recovered`，方便围绕问题发生时间查看前后事件。

开启控制台后会额外记录：

- 应用版本、运行时、操作系统、窗口、配置及输入后端；
- 页面进入/退出、设置页切换、文件拖入及导入结果；
- 选歌、筛选、搜索、Mod 与开始游玩操作；
- 游玩谱面摘要、键位按下/抬起、输入时间来源、每次判定、暂停、恢复、重试、失败和结算；
- 音频启动参数与实际后端状态；游玩期间每秒记录一次播放位置、回调、deadline/cadence miss、overload、underrun、输入队列和判定状态。

控制台操作：

- `暂停/继续`：暂停或恢复屏幕滚动；后台仍继续记录，恢复后会补上缓存内容。
- `清空`：只清空本次内存视图，不删除磁盘日志。
- `复制`：复制当前最多 5000 条环形缓存，包括完整异常堆栈。
- `导出`：在 `%APPDATA%\Yokko\diagnostic-exports` 生成可直接分享的 `.zip`，自动复制路径并打开目录。压缩包包含实时环形缓存、当前 session 的原始 framework 日志、系统清单和最近一次性能快照。
- `打开日志`：打开当前 session 的 framework 与 `diagnostics` 日志目录。
- `关闭` 或 `F12`：停止 Yokko 详细事件采集，并恢复原来的 framework 日志等级。

建议复现问题前开启控制台，问题出现后先点“暂停”，再点“导出”把完整证据包发给开发者。详细模式会记录键盘输入事件；处理敏感文本前应先关闭控制台。
